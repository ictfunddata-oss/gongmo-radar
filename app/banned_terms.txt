# 금칙어 목록 — '많이 찾는 검색어'(F-SVC-18)에서 뺄 부적절한 단어
#
# · 한 줄에 단어 하나. '#'으로 시작하는 줄은 설명입니다. 파일을 고치면 서버를 다시 켜지 않아도 바로 적용됩니다.
# · 검사할 때 공백·특수문자를 모두 없애고 영문은 소문자로 바꿉니다(예: '시 발', '시.발', 'Fuck'이 같은 단어로 걸러짐).
# · 검색어 안에 금칙어가 '포함'되기만 해도 걸러집니다. 이런 검색어는 기록하지 않고, 이미 기록된 것도 화면에 보이지 않습니다.
#   (검색 자체는 막지 않습니다. 이용자가 검색하면 결과는 그대로 나옵니다.)
# · '!'로 시작하는 줄은 예외입니다. 이 단어를 포함한 검색어는 그 부분을 뺀 나머지로만 검사합니다.
#   (예: 금칙어 '시발'이 '시발점', '시발역' 같은 정상 단어를 걸러내지 않게 함)
# · 정상 검색어가 걸러지는 일이 없도록, 다른 단어의 일부로 흔히 쓰이는 짧은 단어는 넣지 않았습니다.
#   (공백을 없애고 검사하므로 '구성기관'의 '성기', '애자일'의 '애자', '한-일 베트남'의 '일베'처럼 우연히 겹치는 단어는 뺐습니다.)
