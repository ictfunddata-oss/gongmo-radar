# 미결 사항

결정이 필요한 쟁점이다. 해결되면 행을 지우지 않고 상태를 '해결'로 바꾸고, 결정 내용은 D-40에 ADR로 남긴다.

| 번호 | 쟁점 | 선택지 | 영향 | 결정 주체 | 상태 |
|---|---|---|---|---|---|
| I-01 | 내역사업 목록(기금 여부·R&D 구분 포함) 확보 | ① 내부 기금운용계획 자료 제공 ② 공개자료로 초안 작성 후 검토 | F-SEL-03·04 판정 방식 전체 | 기금사업성과팀 | 미결 |
| I-02 | 분류 체계 확정 | ① FS-CLS 초안 v0 사용 ② PIMS·팀 기존 체계 적용 | F-CLS-01~03, 검증 데이터 | 기금사업성과팀 | 미결 |
| I-03 | 노출 범위 | 입주 모집·행사 참가 모집·입찰 공고를 공모사업 화면에 넣을지 | F-SEL-05 결정표 | 기금사업성과팀 | 잠정 결정(ADR-015·018·019: 사업 모집만 노출, 입찰·입주 모집·행사·대회·공모전 제외) — 담당자 확인 대기. 입주 외 '단순 모집'의 범위는 사용자 결정 대기 |
| I-04 | 내용이 첨부에만 있는 공고(27.5%) 처리 | ① 제목·본문만으로 판정하고 '정보 부족' 표시 ② 첨부 텍스트만 추출(파일 미저장) | F-CRW-11, F-CLS-07, 정확도 | 기금사업성과팀 | 미결 |
| I-05 | 수집 주기 | 매일 1회 / 하루 2회 / 연초(2~3월) 집중 기간만 상향 | 성과지표 4(적시성) | 기금사업성과팀 | 미결 |
| I-06 | PIMS 연계 방식 | 파일 제공 / 조회 API / DB 직접 적재 | F-SVC-08, D-20 이관 | PIMS 담당·기금사업성과팀 | 미결 |
| I-07 | 형상 관리·운영 환경 | git 저장소 전환, 실행 서버(담당자 PC / 내부 서버) | D-02 §7 | 기금사업성과팀 | 미결 |
| I-08 | AI 공급자·비용 승인 | Claude API 유지 / AX계획상 다른 외부 LLM 비교 | ADR-004, 예산 | 기금사업성과팀 | 미결 |
| I-09 | 성과지표 목표치 | 지표 1~8 목표값 | D-30, 기능별 품질 기준 | 기금사업성과팀 | 미결 |
