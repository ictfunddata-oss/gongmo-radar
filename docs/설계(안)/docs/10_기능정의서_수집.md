## 2. 기능 상세

### F-CRW-02 목록 수집

| 항목 | 내용 |
|---|---|
| 입력 | 게시판 목록 URL, 쪽 번호 |
| 처리 | 목록 표의 행마다 게시물 ID(상세 링크 끝 번호), 목록 번호, 사이트 상태, 제목, 사업구분, 신청기간 원문, 작성자, 게시일을 읽음 |
| 마지막 쪽 판정 | 쪽 링크 번호의 최댓값. '마지막 페이지' 링크는 마지막 묶음에서 사라지므로 쓰지 않음 |
| 출력 | 목록 행 배열, 마지막 쪽 번호 |
| 예외 | 요청 실패는 3회 재시도(2·4·6초 대기) 후 실행 오류로 기록하고 중단 |

### F-CRW-03 상세 수집

| 항목 | NIPA 추출 위치 | 비고 |
|---|---|---|
| 사업구분 | `.gdi1 .bluebox` | 추출률 99.2%(350/353) |
| 신청기간 | `.gdi2` | 추출률 97.7%(345/353), 나머지 8건은 사이트에 '상시모집' 표기 |
| 작성일 | `.infoDt` | 추출률 100% |
| 조회수 | `.infoVw` | |
| 본문 | '내용' 칸 텍스트 | 50자 미만 97건(27.5%) |
| 첨부 목록 | '첨부파일' 칸의 다운로드 링크 | 파일명·확장자·크기·URL. URL의 토큰은 접속마다 바뀌어 만료됨 |

한 건의 상세 수집이 실패해도 전체를 멈추지 않고 오류 건수만 올린다.

### F-CRW-04 증분 수집

| 규칙 | 내용 |
|---|---|
| 시작 | 1쪽부터 읽음 |
| 중단 | 이미 수집한 글이 있는 상태에서, 한 쪽에 새 글이 하나도 없으면 그 쪽까지 처리하고 중단 |
| 갱신 | 읽은 쪽의 기존 글은 상세를 다시 읽어 변경을 반영(F-CRW-06) |
| 실측 | '26.10.1 증분 실행: 1쪽 10건 확인, 신규 0건, 7초 |

### F-CRW-07 구조 변경 감지

| 감지 조건(안) | 판정 |
|---|---|
| 1쪽 목록이 0건 | 오류 — 게시판 URL·구조 변경 의심 |
| 이번 실행의 사업구분·신청기간·작성일 결측률이 직전 30일 평균보다 20%p 이상 높음 | 주의 |
| 상세 요청 오류율 10% 이상 | 주의 |

임계값은 1단계 기관 가동 후 실측으로 조정한다.

### F-CRW-08 접근 정책 준수

| 항목 | 현재 | 목표 |
|---|---|---|
| 요청 간격 | 0.3초(설정 가능) | 기관별 설정, 최소 0.3초 |
| UA | Chrome 브라우저 UA 고정 | 동일 |
| robots.txt | 점검 엑셀로 수동 확인 | 실행 시작 시 자동 확인, 차단 경로면 수집 생략·기록 |
| 개인정보 | 작성자(담당자 이름) 저장 중 | 수요자 화면에 노출하지 않음, 연락처는 수집하지 않음 |
