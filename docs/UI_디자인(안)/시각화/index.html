시각화 시안 5종

수요자 화면에 붙일 시각적 서비스 후보. 실제 DB의 노출·검토 공고 283건으로 그린 시안이며 앱에는 적용하지 않았습니다.

안1

접수 일정 타임라인

사업마다 접수 시작~마감을 가로 막대로 겹쳐 보여 주는 간트형 화면

안2

월간 마감 달력

날짜 칸에 마감·시작 공고를 표시하고 날짜를 누르면 목록을 보여 주는 달력

안3

분야별 트리맵

분야마다 공고 수에 비례한 사각형으로 어느 분야에 사업이 몰리는지 보여 줌

안4

월별 공고 추이

월별 게시 건수를 기관별·분야별로 쌓은 막대 차트

안5

분야 × 대상 히트맵

분야와 지원 대상의 교차 건수를 색 농도로 보여 주는 표
