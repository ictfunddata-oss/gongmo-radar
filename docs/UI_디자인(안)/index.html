공모사업 대시보드 UI 디자인(안)

기존 수집 대시보드(nipa_crawler_dashboard_live.html)를 바탕으로, 화면 문구를 모두 한글로 바꾸고 쓰는 사람과 목적에 따라 4가지 안을 만들었습니다. 모두 실제 수집 데이터로 그려집니다.

안1

운영 현황판

대상: 수집기를 관리하는 담당자
  • 현재 상태를 한 문장으로 요약(접수 중·마감 임박·마지막 수집)
  • 수집 기록·로그 한글화, 데이터 품질(항목 추출률)
  • 16개 대상 기관 수집 가능 여부 현황
기존 어두운 화면 유지
안2

공모사업 찾기

대상: PIMS를 쓰는 수요자(기업·기관)
  • 검색, 접수 상태·공고 유형·지원 분야·지원 대상 필터
  • 카드형 공고 목록, D-day, 접수 기간 진행 막대
  • 입찰·결과 공지는 기본으로 숨김
밝은 PIMS 포털형
안3

접수·마감 일정

대상: 담당자·수요자 공통
  • 앞으로 2주 마감 띠, 월간 달력(접수 시작·마감 표시)
  • 날짜를 누르면 그날 일정 목록
  • 3개월 구간 접수 기간 막대(간트) 차트
달력·타임라인
안4

분석 리포트

대상: 보고·기획(내부 보고서용)
  • 연도·월별 게시 분포, 접수 기간 길이, 사업·분야·유형 구성
  • 그림마다 한 줄 해석 문장을 자동 생성
  • 연도 필터, 인쇄·PDF 저장
인쇄용 보고서형
공통 사항 · 화면 문구 전부 한글 · 접수 상태는 페이지를 연 시각 기준으로 계산 · 마우스를 올리면 상세 값 표시 · 차트마다 '표로 보기' 제공 · 분야·지원대상·공고유형은 AI 분류 기능을 만들기 전까지 쓰는 단어 기준 임시 분류입니다.
