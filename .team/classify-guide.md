# 공고 분류 기준 (코디네이터 소유 · 워커는 읽기만)

수집한 공고 한 건을 아래 셋 중 하나로 분류한다. 판단 근거는 입력에 있는 제목·말머리(biz)·본문 앞부분·첨부 파일 이름뿐이다. 추측으로 단정하지 말고 confidence로 확신 정도를 표시한다.

## 분류(class)

| class | 뜻 | 단서 |
|---|---|---|
| 입찰공고 | 기관이 **계약**을 맺어 물품·용역·공사를 살 업체를 찾는 글 | [입찰공고]·[조달입찰공고]·(사전규격 공개) 말머리, 용역·구매·제작, 입찰참가자격, 나라장터(G2B), 계약방법, 제안요청서, 과업지시서, 규격서, 사업예산·추정가격 |
| 공모지원사업 | 기업·기관·개인·팀을 뽑아 **지원**(자금·바우처·공간·교육·해외진출·장비·컨설팅 등)을 주거나, 정부 지원사업의 수행(주관)기관을 뽑는 모집 글 | 지원사업, 모집, 참여기업·참가기업·교육생·입주기업 모집, 지원대상, 지원내용, 협약, 보조금, 사업계획서, 신청서 |
| 기타 | 위 둘이 아닌 글 | 결과 발표(선정·평가·심사·낙찰 결과), 설명회·세미나·행사 단순 안내, 사칭·보안 주의, 일반 공지, 채용, 규정·지침 안내, 포스터·홍보물 |

## 경계 규칙

1. 돈의 성격으로 가른다. 선정된 쪽이 **계약 대가**(계약금액·입찰가격)를 받으면 입찰공고, **지원금·보조금·협약 사업비**를 받거나 혜택(교육·부스·공간)을 받으면 공모지원사업이다.
2. '운영기관·수행기관 모집'은 근거로 가른다. 입찰·나라장터·가격 제안·계약이 보이면 입찰공고, 협약·보조금·사업계획서가 보이면 공모지원사업이다.
3. 협상에 의한 계약 방식의 '공모'(예: 법률자문 법인 선정, 용역 사업자 공모)는 입찰공고(sub: 협상공모)다.
4. 전시회 부스 참가기업·교육생·입주기업처럼 지원 혜택을 받는 참가자 모집은 공모지원사업(sub: 참가·교육)이다. 혜택 없이 참석만 받는 행사 안내는 기타(sub: 행사·설명회)다.
5. 정정·연장·취소·중단·재공고는 원래 공고의 분류를 따르고 sub를 '변경·취소'로 둔다. 예: '운영 용역 모집 - 잠정 중단 안내' → 입찰공고 / 변경·취소.
6. 선정·평가·심사 결과 발표는 무엇의 결과든 기타(sub: 결과)다.
7. 근거가 모자라면 가장 가까운 분류를 고르고 confidence를 low로 둔다. '모르겠음' 분류는 없다.

## 하위 유형(sub)

- 입찰공고: 입찰 / 사전규격 / 협상공모 / 변경·취소
- 공모지원사업: 지원사업 / 수행기관 / 참가·교육 / 변경·취소
- 기타: 결과 / 행사·설명회 / 안내 / 채용 / 기타

## 출력 형식 (JSON Lines, 입력 1건 = 출력 1줄, 입력과 같은 순서)

```json
{"ann_id": 123, "class": "입찰공고", "sub": "입찰", "confidence": "high", "reason": "말머리 [입찰공고], 용역 계약·입찰참가자격 언급"}
```

- class는 `입찰공고` · `공모지원사업` · `기타` 중 하나, confidence는 `high` · `mid` · `low` 중 하나.
- reason은 한 문장, 80자 이내. 입력에 있는 단서를 적는다.
