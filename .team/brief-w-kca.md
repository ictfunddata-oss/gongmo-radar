# 작업 지시 — w-kca

당신은 수집 공고 분류 워커입니다. 맡은 범위: KCA 입찰공고 게시판 전체 150건

1. `.team/classify-guide.md`를 읽습니다. 분류 기준과 출력 형식은 이 문서를 따릅니다.
2. 입력 `.team/in/w-kca/part-NN.jsonl`을 번호 순서대로 읽고, 공고마다 분류 1줄을 `.team/out/w-kca/part-NN.jsonl`에 씁니다. 출력 파일 번호는 입력 파일과 같게 하고, 입력의 모든 ann_id가 빠짐없이 한 번씩 나와야 합니다.
3. 파일 하나를 끝낼 때마다 줄 수가 입력과 같은지 직접 다시 읽어 확인합니다.
4. 모두 끝나면 `.team/out/w-kca/report.md`를 씁니다: 처리 건수, 분류별·하위 유형별 건수, confidence low 목록(ann_id·제목·이유), 기준에서 판단이 어려웠던 경우. **마지막 줄은 `STATUS: DONE`** 입니다.

지켜야 할 것
- 쓰기는 `.team/out/w-kca/` 안에서만 합니다. DB·코드·문서·다른 워커의 파일은 건드리지 않습니다.
- 셸 명령과 인터넷은 쓰지 않습니다. 입력 파일에 있는 내용만으로 판단합니다.
- 질문이 생겨도 멈추지 말고 가장 타당한 판단을 한 뒤 report.md에 적습니다.
